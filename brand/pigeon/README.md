# the pigeon

One bird, a few moods. `contact-sheet.jpg` shows the whole kit at a glance.

| folder | use it on |
|---|---|
| `ink/` | paper, kraft, anything light |
| `light/` | the grass, the clay, anything dark |
| `filled/` | photos and busy color (he brings his own paper) |

Each folder has `png/` (transparent, about 2000px wide) and `svg/` (for Figma, print, any size).

| pose | file |
|---|---|
| the letter | `pigeon-letter-*` |
| delivered | `pigeon-delivered-*` |
| homing | `pigeon-flight-*` |
| puffed up | `pigeon-puff-*` |
| the stretch | `pigeon-stretch-*` |
| two of us | `pigeon-pair-*` |
| wrong table. | `pigeon-lost-*` |

The drawings live in `../pigeons.html`. Change them there, then run `node brand/render.js` from the repo root.
